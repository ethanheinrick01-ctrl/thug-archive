# Song context

The catalog has 297 local archive entries. As of November 1, 2026, 153 have a community-era attribution or tentative match, 79 have a source-file date or other dated clue, and seven have an official song-release reference. The counts overlap. Other entries remain unassigned where a safe match was unavailable. A matching title and duration do not authenticate the exact archive mix, and an era attribution does not establish an intended album placement or recording date.

Research sources include the public [Young Thug tracker and era pages](https://www.unreleased.world/youngthug), the [Lil Uzi Vert era pages](https://www.unreleased.world/liluzivert), and official Apple Music release listings linked from individual song menus. File dates, preview years, and official release dates are labeled separately. The community tracker is not an artist or label session log. Some songs share a name with unrelated recordings: the possible tracker match for the archive's “Want Me Dead” is distinct from the released song on *BUSINESS IS BUSINESS*, and the four-minute “Love You More” is a possible match for a Hy!£UN35-era song rather than the separate *Punk* recording. “Birthday Boy” has contradictory file and leak dates in the tracker, so its displayed file year must not be read as a confirmed recording year. Original research snapshots stay in ignored local storage.

For sound suggestions, local processing used the LAION CLAP music-and-speech audio model on three ten-second excerpts from each of the 297 files. Prompt comparisons provided tentative guitar-like, keyboard-like, synth-like, and hard-drums groups; ranked embedding similarity provided up to five neighboring songs per entry. Similarity can reflect voice, rhythm, production, or instruments, and both classifications and neighbors can be wrong. Short excerpts can also miss an instrument elsewhere in a song. The existing three-song Guitar-led collection is separate from these automated candidates. Raw audio, fingerprints, embeddings, and local research snapshots are not included in the repository or sent to the model provider.

Artist browsing uses archive credits and source-supported additions. Uncertain credits remain unconfirmed. Context is shared across rows, likes, playlists, menus, and player views; new research does not change likes, playlist membership, or queue order.

Discovery uses separate facets for sound, artist role, community era, date meaning, version and evidence. Choices within a facet are alternatives; different facets must all match. File years, recording years, previews and release references are never collapsed into a single release-year field. Unknown remains selectable. A song may belong to several sound families. “Guitar-led” retains the three existing listening picks; “Guitar-like” retains the 20 short-excerpt model candidates. Their union contains 21 recordings. This UI change adds no new listening classifications.

Search uses the same normalized titles, aliases and resolved metadata in the archive, liked songs, playlists, recent uploads, history and queue. It does not search warning/disclaimer prose. Every recording stays visible; alternate versions do not disappear behind a representative. Queue counts count occurrences, including repeats. Saving results creates an ordinary playlist snapshot.
